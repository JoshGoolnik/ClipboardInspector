# :clipboard: Clipboard Data Inspector
The Clipboard Data Inspector is an extension for [Power Toys Command Palette](https://learn.microsoft.com/en-us/windows/powertoys/command-palette/overview). 

It was initially called Clipboard Inspector until I realised that name was taken in the Microsoft Store 😒

## ➕ Usage and Benefits
You can view all the formats of data currently stored on your clipboard, along with the raw hex format! I mean, who wouldn't want that, right? Right? Hello..?

## 💻 Installation
If you'd like to install the finished product just follow these steps:
1. Install [PowerToys](https://apps.microsoft.com/detail/xp89dcgq3k6vld) if you haven't already!
2. Install [Clipboard Data Inspector](https://apps.microsoft.com/detail/9n5wpnfm4jfh)
3. Open Power Toys.
4. In Power Toys open Command Palette.
5. In Command Palette just type "Clipboard Data Inspector" in the top menu, then click the icon!
